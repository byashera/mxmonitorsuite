## Ne amaçla kullanılabilir?

> Sahadaki S7 cihazlara temas etmeden PLC'ler ile haberleşerek cihaz tag ve verilerini çeker. Çekilen veriler anlık olarak izlenebilir. Birden fazla PLC aynı anda kontrol edilebilir.

## Gerekisinimler:
> Herhangi bir ek program veya yapıya ihtiyaç duymaz.

# Not: Program henüz deneme sürümündedir. İmzalanmadığı için Windows Güvenlik hatası verebilir!
